## ハーモニー — 全部7th、1小節動かない、ルートが下りる

4小節ループを23回ぶん重ねてから推定した結果。

| 小節 | 1-2拍 | 3-4拍 |
|---|---|---|
| 1 | **G♭maj7 / G♭maj9**（1小節まるごと動かない） | 同じ |
| 2 | **Fm7 / Fm9** | **B♭ ルートの和音**（質は確信度低め） |
| 3 | **E♭m7 / E♭m9** | **Cm7♭5**（ハーフディミニッシュ） |
| 4 | **D♭7sus4** | → A♭ 系へ抜けてループ頭に戻る |

ベースのルートは **G♭ → F → B♭ → E♭ → C → D♭ → A♭**。

D♭ major で読むと IVmaj9 → iii7 → vi7 → ii7 → viiø7 → I7sus4。
B♭ minor で読むと VImaj7 → v7 → i7 → iv7 → iiø7 → III。
**どちらとも取れる**まま回り続けるのがこの曲の浮遊感の一因で、しかも最後の D♭7sus4 は
G♭ に向かう V7 として働くので、ループの頭 G♭maj7 が「帰ってくる場所」に聴こえる。

- **3和音がひとつも無い。** maj7・m7・m7♭5 だけ。7thが入ると和音の中に長7度/短7度の
  ぶつかりが常駐して、「明るい/暗い」の二択から外れる。ループ全体の質感はここで決まっている
- **1小節目がまるごと動かない。** 和音が止まっている時間が長いほど、その上のメロディとラップは
  自由に聴こえる。4小節のうち1小節を止めるのが余白の作り方
- **ルートが G♭→F→E♭→D♭ と下りる。** 下行するベースは重力に沿った動きで、ため息のように聴こえる。
  B♭ と C は下行の合間に挟まる経過的なルート
- **Cm7♭5 が入る。** マイナーキーの iiø は解決したがっている音で、これがあるから3小節目で一度緊張して
  4小節目で緩む。動きの少ないループに呼吸が生まれている

## グルーヴ — 完全に打ち込み。癖は2つだけ

**定石通りのところ**

- クラップ/スネアが2拍と4拍。ここが揺るがないから、上モノが自由に漂っても曲が崩れない
- ハットは8分の刻みに16分の合いの手。9〜10発/小節はミッドテンポHIPHOPの標準的な詰め方
- 97.6 BPM は「歩く速さ」の帯域。ラップの語数と、上モノを聴かせる余白が両立する

**この曲の癖**

- **キックが小節の後半をほぼ空ける。** 前半に密集し、3拍のあと4拍まわりはほぼ無音。
  低域が空く時間が小節ごとに来るので、そこにベースとボーカルが入れる。
  「後半を空ける」は前半の密度と対になっていて、片方だけ真似しても同じにならない
- **ハットの最強点が拍頭ではなく "a"（16分の4つ目）。** 2拍前と3拍前の "a" が最大。
  拍の直前に置くと前へ倒れる推進力になる。拍頭を強くする刻み方とは体感がかなり変わる

**ハネていない**のは、この BPM 帯のサンプリング系HIPHOPが軽くハネることが多い印象を踏まえると、
意図的な選択に見える。揺らぎで情緒を作っていない。

ベースは「短い音を少なく置く」タイプ。中心音域 E1-A♯2（中央値 C2）、1音の長さの中央値が16分2.3個ぶん。
コードの下を歌わずにルートだけ点で置いていて、拍頭ではなく**拍の直後にずらして入る**のが癖。

> 深掘りするなら: 「キックの後半空け」と「ハットの前ノリ」のどちらが推進力に効いているか、
> 片方ずつ潰して聴き比べると分かる。

## 音色と帯域 — 上モノは中低域だけで、声と住み分けている

- **上モノ（エレピ系）は 250Hz-2kHz に 87% が集中し、2kHz以上がほぼ空。** つまり「刺さる帯域」を持っていない。
  一方ボーカルは2kHz以上に50%ある。**帯域が最初から住み分けていて、EQで削って作った隙間ではない**。
  この形なら上モノを大きめに出してもラップが埋もれない
- **アタック31ms・250ms後に元の0.30。** 叩いて減衰する音で、伸ばして支えるパッドではない。
  減衰する＝隙間が定期的に開くので、ループが煩くならない
- **ステレオ幅は 上モノB 0.62 > エレピ系 0.33 > ボーカル 0.16。** 上モノを外に、声を真ん中に置いている。
  真ん中が空くのでラップの居場所が確保される

> 「エレピっぽい」の正体は重心1kHz前後・2kHz以上ほぼ無し・アタック30ms・減衰型、の4点の組み合わせ。
> シンセで似せるなら、音色選びより先にこの4つを合わせにいくのが近道。

## 構成 — 音量は動かさず、要素の出入りだけで作る

| 小節 | 編成 | ミックスRMS |
|---|---|---|
| 1-8 | 上モノ + 声（ドラムもベースも無し） | **-14.2dB** |
| 9-12 | + ドラム | -10.0dB |
| 13-16 | + ベース（ここで全部そろう） | -9.9dB |
| 17-24 | 上モノが A から B に入れ替わる | -9.5dB |
| 25-28 | ドラム + ベース + 上モノA + 声 | -10.5dB |
| **29-32** | **ベースも上モノも抜く** | -10.3dB |
| 33-44 | ドラム + ベース + 上モノA + 声 | -9.8dB |
| 45-48 | + 上モノB | -9.4dB |
| **49-56** | **またベースを抜く（8小節）** | -10.4dB |
| 57-64 | 全部 + 上モノB | -9.9dB |
| 65-72 | ドラム + ベース + 上モノA + 声 | -10.4dB |
| 73-80 | **ラップが終わる** | -11.8 → -12.0dB |
| 81-92 | + ギター | -10.7dB |

- **13小節目以降、ミックスの音量はほぼ動かない。** -9.4 〜 -12.0dB の 2.6dB幅に収まっている。
  ベースを丸ごと8小節抜いた 49-56 でさえ -10.4dB で、戻したあと（57-64）の -9.9dB と 0.5dB しか違わない。
  **山谷を音量で作っていない**
- **なのに聴感上は明らかに変化がある。** つまりエネルギー曲線は**音量ではなく、要素の数と帯域の占有**で
  作られている。ベースを抜くと低域が空き、上モノAをBに替えると中域の質感が変わる。
  RMS が同じでも「詰まり具合」が変わるので、抜き差しが効く
- これはマスターが強く潰されていること（ピーク +0.4dBFS / 平均 -12.1dBFS）の裏返しでもある。
  何を足しても引いても、リミッターが同じ音量に均してしまう
- **唯一の明確な段差はイントロ。** 冒頭8小節だけ -14.2dB で、全部そろうと -9.9dB。**4.3dBの落差**。
  ここだけは音量でも引きを作っている
- **コードループは4小節、編成の単位は8小節。** ループ2周ごとに編成が変わる形
- **ラップが終わってからギターが入る**（81小節〜）。音量は上がらないが、**それまで一度も出ていない音色**が
  最後に来る。新しい音色を取っておくのは、音量を上げられないマスターで変化を作る手段になる

## 「メロディアスさ」は何でできているか

「HIPHOPの中のメロディアスなやつ」として聴いているものは、測った範囲では次の4つで説明がつく。
効きが大きい順:

1. **和音が全部7th以上。** 三和音は「明るい/暗い」の二値だが、7thが入ると和音の内部に緊張が
   常駐して感情のラベルが貼れなくなる＝「なんか良い」になる
2. **1小節ぶん動かないコードで毎ループ始まる。** コードが毎拍動くと、耳は和音の追跡に使われて
   メロディを聴かなくなる。止まっている時間があるから旋律的に聴こえる
3. **上モノが2kHz以上を持っていない。** 高域を持たない音は「奥」に聴こえる。前に出てこないぶん
   ずっと鳴っていても疲れない＝長く聴ける＝旋律として印象に残る
4. **ドラムが情緒にまったく関与していない。** 揺れ0・ハネ0で、リズムは推進力だけを供給している。
   情緒の担当がハーモニーに一本化されるので、和音の性格がそのまま曲の性格になる

逆に言うと、**リズムを作り込んでも「メロディアス」にはならない**。似た雰囲気を狙うなら
優先順位は「コードの積み方 → 上モノの帯域 → 構成 → リズム」の順になる。

## 耳で検算する

[listen/](listen/) に確認用の短いクリップを、確認する順に番号を振って切り出してある。
Finder で開いてファイルを選び**スペースキー**（Quick Look）を連打すれば一周できる。全18本・合計4分。

```sh
open ~/Music/daw/references/rau-def-freeze/listen
```

| クリップ | 何を判定するか |
|---|---|
| `01-click-head` / `01-click-tail` | **BPM と小節頭**。高いクリックが小節頭、低いのが拍。曲頭と曲尾の両方でズレなければ正しい |
| `02-chords-check` | **コード進行**。推定した和音をサイン波で重ねてある。**合っていれば曲に溶け、違えば濁る**。特に2小節目後半と4小節目後半 |
| `03-loop-only` | 02 と同じ区間のコード無し版。聴き比べ用 |
| `04-stem-*-loud` | 各ステムの素性（一番大きい区間） |
| `04-stem-*-quiet` | **分離の破綻・幽霊音**（鳴っているが小さい区間。破綻が一番聴こえるのはここ） |
| `05-midi-*` | **basic-pitch の精度**。左が原音、右がMIDIをサイン波で |

メモしてほしいのは2つ:

1. 各クリップが OK か NG か（NG ならどう聴こえたか一言）
2. **「特にここが好き」な瞬間を2〜3個**（秒でも小節番号でもよい）。次の曲の分析でそこを重点的に見る
