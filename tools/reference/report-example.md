| 系統 | 中身 | 出入り |

系統は AI のパート分解（demucs）が振り分けた先の名前で、実際にその楽器が鳴っているとは限らない（シンセが piano に入る等）。「中身」の呼び名は音色の実測からの推定。
数値の読み方: 重心=音のエネルギーの真ん中の高さ（低いほど太く暗い）・幅=左右の広がり（0=モノ・1=いっぱい）・250ms後=鳴ってから0.25秒後に残っている音量（元の音量比）。

### 構成 — 楽器の抜き差しは4〜8小節ごと、大きく3ブロック

- **1-12小節 イントロ**: 上モノと声だけで始まり（-14.6dB）、9小節目にドラムが入る
- **13-72小節 本編**: 13小節目で全部そろう（-9.9dB）。ベースやエレピを何度も抜き差しするが、**音量は動かない**
- **73-92小節 アウトロ**: 73小節目でラップが終わり、81小節目にギターが加わる

音量がはっきり変わるのはイントロだけ（約4dB）。それ以降はずっと -9.4〜-12.0dB の狭い幅に収まっている（詳細は[構成の節](#構成--音量は動かさず要素の出入りだけで作る)）。

## ハーモニー — 三和音を使わず、1小節目だけ途中で和音が変わらず、ベースは F#→F→D#→C# と下りていく

同じ4小節の繰り返しを23回ぶん重ねて平均してから推定した（1回ごとの読み間違いに強くなる。どのパートから読んだかは付録「ループ長の判定」）。

| 小節 | 前半（1-2拍） | 後半（3-4拍） |
|---|---|---|
| 1 | **F#maj9** | **F#maj7** |
| 2 | **Fm9** | **A#maj7** |
| 3 | **D#maj9** | **C7sus4** |
| 4 | **C#7sus4**（確信度低め） | **A#m9**（確信度低め） |

「確信度低め」= 他の和音より推定の自信がはっきり低い枠。耳での確認（listen/02）に回す。

各和音の土台の音（ルート。コード名の頭文字で、だいたいベースが弾く音）は
**F# → F → A# → D# → C → C#** と並ぶ。キーの主和音 C# が現れるのは4小節目の
C#7sus4（sus4 = 三度を4度に置き換えて、明るい/暗いの判定を保留する和音）だけ。進行はいつも
IV（キーの4番目の音 F# をルートにした和音）に帰ってきて、そこからまた回り続ける。

- **三和音がひとつも無い。** 表の8マス全部に 7th か 9th が乗る（7th・9th = 三和音の3音の外に
  重ねる音。「テンション」と呼ぶ）。7th が入ると和音の中に長7度/短7度のぶつかりが常駐して、
  「明るい/暗い」の二択から外れる。ループ全体の質感はここで決まっている
- **1小節目だけ、途中で和音が変わらない。** 他の小節は半小節ごとに切り替わるが、1小節目は
  F#maj9 → F#maj7 — 9th の付け外しだけで実質同じ和音が1小節鳴り続ける。和音が止まっている
  時間が長いほど、その上のメロディとラップは自由に聴こえる。4小節のうち1小節を止めるのが
  余白の作り方
- **ルートが F# → F → D# → C# と半音・全音で下りる。** 下行するベースは重力に沿った動きで、
  ため息のように聴こえる。A# と C は下行の合間に挟まる経過的なルート
- **終わり際の2マスが sus4 で解決を保留する。** C7sus4 → C#7sus4 と宙づりのまま、
  頭の F#maj9 で開放する。3小節目後半で一度緊張して1小節目で緩む — 動きの少ないループに
  呼吸が生まれている

4小節目の2マスは確信度低め。C#7sus4 → A#m9 が正しければ、ループの結びで一度 A# minor
（同じ7音を暗い側から使う調）の響きに寄ってから頭に戻る形になる。ここの当否で結末の表情が
変わるので耳（listen/02）に回す。

> 真似するなら: 全部の和音に 7th を足し、ループ頭の1小節は動かさないこと。sus4 のマスを、
> ふつうに三度を入れた和音で弾いてから sus4 に差し替えると、「保留」が何を効かせているか分かる。

## グルーヴ — 完全に打ち込み。癖は2つだけ

**定石通りのところ**

- スネア/クラップは2拍が最大（1.00）・4拍が 0.80。2拍と4拍の位置がここで揺るがないから、
  上モノが自由に漂っても曲が崩れない
- ハットは8分の刻みに16分の合いの手。ミッドテンポHIPHOPの標準的な詰め方
- 97.6 BPM は「歩く速さ」の帯域。ラップの語数と、上モノを聴かせる余白が両立する

**この曲の癖**

- **キックが小節の後半をほぼ空ける。** 1拍まわり（0.83〜1.00）に密集し、3拍のあとは 0.25 以下で
  ほぼ無音。低域が空く時間が小節ごとに来るので、そこにベースとボーカルが入れる。「後半を空ける」は
  前半の密度と対になっていて、片方だけ真似しても同じにならない
- **ハットの最強点が拍頭ではなく "a"（16分の4つ目）。** 2拍直前の "a" が 0.82、3拍直前の "a" が
  最大の 1.00。拍の直前に置くと前へ倒れる推進力になる。拍頭を強くする刻み方とは体感がかなり変わる

**ハネていない**（スウィング比 0.500 ちょうど）。この速さのサンプリング系HIPHOPは軽くハネる
ことが多いので、あえてハネさせない選択に見える。揺らぎで情緒を作っていない。

ベースは「短い音を少なく置く」タイプ。中心音域 F1–A#2（中央値 C#2）、1音の長さの中央値が16分
2.3個ぶん。打点の山は拍頭でなく**その直後の16分**にある（2拍直後 0.33・3拍直後 0.39 に対し
2拍頭 0.08・3拍頭 0.19）。グリッドからのズレはドラム（±6ms）とは桁違いの平均 39.5ms で、
**揺れの担当はベース一本に集約されている**。

> 深掘りするなら: 「キックの後半空け」と「ハットの前ノリ」のどちらが推進力に効いているか、
> 片方ずつ潰して聴き比べると分かる。

## 音色と帯域 — 上モノは中低域だけで、声と住み分けている

- **エレピ系は 250Hz–2kHz に 88% が集中し、2kHz以上がほぼ空（5.6%）。** つまり「刺さる帯域」を
  持っていない。重心は 1041Hz と低い。
  一方ボーカルは 2kHz以上に 50% ある。**帯域が最初から住み分けていて、EQ で削って作った隙間では
  ない**。この形なら上モノを大きめに出してもラップが埋もれない
- **アタック 30ms、鳴って0.25秒で元の3割まで減衰。** 叩いて減衰する音で、伸ばして支えるパッドではない。
  減衰する＝隙間が定期的に開くので、ループが煩くならない
- **ステレオ幅は 広がり系 0.62 > エレピ系 0.33 > ボーカル 0.16。**
  上モノを外に、声を真ん中に置いている。真ん中が空くのでラップの居場所が確保される

> 「エレピっぽい」の正体は重心 1kHz 前後・2kHz 以上ほぼ無し・アタック 30ms・減衰型、の4点の
> 組み合わせ。シンセで似せるなら、音色選びより先にこの4つを合わせにいくのが近道。

> だけで、この曲の形になる。

## 「メロディアスさ」は何でできているか

「HIPHOPの中のメロディアスなやつ」として聴いているものは、測った範囲では次の4つで説明がつく。
効きが大きい順:

1. **和音が全部 7th 以上。** 明暗のラベルが貼れない響きが常駐する（ハーモニー節）＝「なんか良い」
   の正体
2. **毎ループ、1小節動かないコードで始まる。** コードが毎拍動くと耳は和音の追跡に使われる。
   止まっている時間があるから旋律を聴ける
3. **上モノが 2kHz 以上を持っていない。** 高域を持たない音は「奥」に聴こえる。前に出てこないぶん
   ずっと鳴っていても疲れない＝長く聴ける＝旋律として印象に残る
4. **ドラムが情緒にまったく関与していない。** 揺れ0・ハネ0で、リズムは推進力だけを供給している
   （グルーヴ節）。情緒の担当がハーモニーに一本化されるので、和音の性格がそのまま曲の性格になる

逆に言うと、**リズムを作り込んでも「メロディアス」にはならない**。似た雰囲気を狙うなら
優先順位は「コードの積み方 → 上モノの帯域 → 構成 → リズム」の順になる。

判定の線: コード構成音率 ≥0.8 かつ ±30ms内 ≥0.7 →「統計用途OK」（譜面としては使えない。持続音を短い音に刻む）。ボーカルの ±30ms内 が低いのは歌がグリッドに乗らないだけで正常。

**ステム分離**

4分割は加算残差 -19.6dB（条件つき（分析には使えるが音として使うのは避ける））、6分割は -14.9dB（疑う）。

休符区間の残留（ピーク比）: guitar -66.7dB / vocals -64.8dB / other -63.1dB / bass -61.4dB / piano -55.7dB / drums -18.4dB。
曲中ずっと鳴っているステム（drums 等）ではこの数字は意味を持たない — 休符が無いだけで分離が汚いわけではない。

## 耳で検算する

[listen/](listen/) に確認用の短いクリップを、確認する順に番号を振って切り出してある。
Finder で開いてファイルを選び**スペースキー**（Quick Look）を連打すれば一周できる。

```sh
open ~/Music/daw/references/rau-def-freeze/listen
```

| クリップ | 何を判定するか |
|---|---|
| `01-click-head` / `01-click-tail` | **BPM と小節頭**。高いクリックが小節頭、低いのが拍。曲頭と曲尾の両方でズレなければ正しい |
| `02-chords-check` | **コード進行**。推定した和音をサイン波で重ねてある。**合っていれば曲に溶け、違えば濁る** |
| `03-loop-only` | 02 と同じ区間のコード無し版。聴き比べ用 |
| `04-stem-*-loud` | 各ステムの素性（一番大きい区間） |
| `04-stem-*-quiet` | **分離の破綻・幽霊音**（鳴っているが小さい区間。破綻が一番聴こえるのはここ） |
| `05-midi-*` | **basic-pitch の精度**。左が原音、右がMIDIをサイン波で |

メモしてほしいのは2つ:

1. 各クリップが OK か NG か（NG ならどう聴こえたか一言）
2. **「特にここが好き」な瞬間を2〜3個**（秒でも小節番号でもよい）。次の曲の分析でそこを重点的に見る
