# Changelog

LaLa（旧名 daw）の更新履歴。形式は [Keep a Changelog](https://keepachangelog.com/ja/1.1.0/) ベース、バージョニングは [SemVer](https://semver.org/lang/ja/)。

## 書き方

このセクションは AI が release.sh の pause 中に `[Unreleased]` を埋めるときの判断基準でもある。

### フォーマット

- 1 項目 = 1 行の `- ` bullet。インライン Markdown は `` `code` ``、`**strong**`、`[label](url)` のみサポート（Sparkle description の HTML 変換が対応するのはこれだけ）
- ユーザー目視で気づく変更だけ書く（内部リファクタ・ドキュメント変更は除く）
- 文体は体言止め（「〜を追加」「〜問題を修正」。「〜しました」体は使わない）

### カテゴリ

```
✨ Added       — 新しい機能・ボタン・画面・ショートカット
📝 Changed     — 既存機能の挙動・デフォルト値・配置・配布形式の変更
🐛 Fixed       — 「期待通りに動かなかった」のが直った
🗑️ Removed     — UI 要素・機能・ショートカットの削除
```

迷ったら **ユーザーが画面でどう感じるか** で選ぶ。

## [0.12.0] - 2026-08-20
### ✨ Added
- オーディオリージョンの**非破壊の移調・タイムストレッチ**を追加（右クリック →「移調・伸縮…」の吹き出し。移調は ±12半音のスライダー、伸縮は小節数で指定し倍率を併記。長さだけ変わりピッチは連動しない。移調中のリージョンは隅に `+2` のようなバッジを表示。吹き出しを開いてから閉じるまでが undo 1件）
- ループのおすすめから敷いた素材に、プロジェクトのキー/BPMへ合わせる移調量と小節数を自動適用
- ヘッダーに**サイクル（ループ再生）ボタン**を追加
- ヘッダーにFXパネルを開き直すボタン（◯にi）を追加（×で閉じている間だけ表示。以前は `I` キーしか戻り口がなかった）
- SENDSのバス名ピル（Reverb A/B・Delay）をクリックすると送り先バスの詳細エディタへ直行（FXパネル・ミキサー共通。ピルにホバー表現）

### 📝 Changed
- 上部バーとmacOSのタイトルバーを**シルバー**に変更（Logicのツールバー準拠。プロジェクト選択画面は暗いまま）。ウィンドウタイトルは中央に表示
- トランスポートを ■ ▶ ● の**役割固定の3ボタン**に変更（状態は点灯で表示。▶/■が入れ替わる方式は緑の停止ボタンに見えていた）。LCDの左右に再配置し、枠なしの見た目に
- メトロノームONの表示色を紫に変更。サイクルボタンはメトロノームの右に配置
- FXパネルのルックを刷新（ハードウェア風のノブ・メーター窓・ラックのピル左端にON/OFFのLED。FXごとに固有色を割り当て、線・点灯目盛り・LED/選択枠で統一）
- パンノブをハードウェア風のノブ（双極の目盛り）に変更。値はノブの中にLCDと同じ等幅書体で表示
- Sendsの小ノブを大ノブと同じ描き方に統一（30px・目盛り7本）

### 🐛 Fixed
- EQのOFF状態のハイパス点をドラッグしても効かないように見えた問題を修正（ドラッグすると自動でONになる）
- EQの ±24dB 付近の点がグラフの端に乗って掴めなかった問題を修正
- プロジェクトを開いた直後、FXパネルのボタンがOFF表示のままだった問題を修正
- URL取り込みでYouTubeが 403 で失敗する問題を修正

## [0.11.0] - 2026-08-17
### ✨ Added
- センドバスにエフェクトの実体を追加: **Reverb A/B**（Size・Damp・Width・Pre-delay・Low Cut の5ノブ。A=短めRoom系・B=長めHall系の初期値）と **Delay**（テンポ同期 Time 1/16〜1/2・Feedback・Tone・Ping-pong）。各トラックの send ノブが実際に残響・エコーの量として効くように
- **Master Limiter** を追加（Gain・Ceiling・Release の3ノブ・lookahead 2ms 固定のブリックウォール。Masterの[Limiter]スロットから開く）
- マスターメーター群を追加: **LUFS**（short-term＋integrated・-14/-9 ターゲットライン）・**相関**・**トゥルーピーク**（Limiterエディタ内に常設）
- 書き出し完了時に integrated LUFS / トゥルーピークを自動計測して表示
- トラックFXに **Sat**（サチュレーション。Drive・Mix の2ノブ＋伝達カーブ・倍音バー表示）を追加
- トラックFXに **Lo-fi**（Wow・Tone・Noise・Crush の成分別4ノブ。レコード質感の劣化系）を追加

### 📝 Changed
- FXストリップを `[EQ][Comp][Sat][Lo-fi][Ext]` の固定5枠に拡張（ミキサー・FXパネルとも）
- センドバスは素通し（音量が増えるだけ）から full wet のエフェクト返しに変更（過去に send を上げて保存したプロジェクトは聴こえ方が変わる）
- 書き出しのテールをバスFXの残響・エコーが減衰しきるまで延長（上限30秒・上限到達時はフェードで自然に終了）

## [0.10.0] - 2026-08-15
### ✨ Added
- トラックCompを追加（FXパネルのCompスロットから開く。Threshold・Ratio・Attack・Release・Make Upの5ノブで、ダブルクリックで既定値にリセット。伝達カーブとGR履歴・GRメーターで掛かり方が見え、低域で揺れるときの `Detector HPF 80Hz` トグル付き）
- ミキサー・FXパネルのCompピルにミニGRバーを追加（エディタを開かなくても掛かり具合が見える）
- `⌘B` の書き出しと `⌘E` のリージョン書き出しにCompを反映（再生と同じ音で書き出される）

## [0.9.0] - 2026-08-15
### ✨ Added
- トラックEQを追加（FXパネルのEQスロットから開く。ハイパス・ベル×2・ハイシェルフの4バンド構成で、カーブ上のドラッグで周波数・ゲイン、スクロールでベルのQ、ダブルクリックで0dBリセット）
