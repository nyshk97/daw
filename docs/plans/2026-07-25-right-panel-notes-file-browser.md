# 右パネル（プロジェクトメモ＋オーディオファイルブラウザ）

## 概要・やりたいこと

Logic Pro の画面右側にあるブラウザ領域を参考に、LaLa のメイン画面へ開閉・リサイズ可能な右ドックを追加する。

- **第1スライス**: 右パネルの器と、プロジェクトごとの自由記述メモを完成させる
- **第2スライス**: Mac 内の音声ファイルをフォルダ階層から探し、その場で試聴してタイムラインへ取り込めるファイルブラウザを同じ右パネルへ追加する
- 多機能な素材管理・タグ・検索・波形編集は入れず、「探す・聴く・置く」に絞る

## 前提・わかっていること

### /dig（2026-07-25）で決定した仕様

**右パネル共通**

| 項目 | 決定内容 |
|---|---|
| 配置 | 上部バーの下から画面下端まで伸びる右ドック。右パネルを除いた中央領域にタイムラインと下部エディタを配置する |
| 初期状態 | プロジェクトを開いた時点では閉じている |
| 開閉・切替 | 上部バー右側のアイコンで操作。閉じているときに押すとその内容で開く、別アイコンで内容を切り替える、選択中アイコンの再クリックで閉じる |
| 幅 | 既定 300px。右境界ではなくタイムラインとの左境界をドラッグし、240〜480pxで変更可能 |
| 状態保持 | 開閉状態・幅・選択内容はプロジェクトを開いている間だけ保持。次にプロジェクトを開いたときは「閉じる・300px」へ戻す |
| ショートカット | 初版はアイコン操作のみ。新しいキー割り当ては追加しない |

**プロジェクトメモ（第1スライス）**

- プロジェクトごとに1つの複数行プレーンテキスト
- 入力した時点でプロジェクトを未保存状態にする
- `⌘S` またはプロジェクトを閉じる／終了するときの既存保存確認で `project.json` に保存する
- パネルを閉じただけでは保存しない
- テキスト編集中の文字入力・Space・改行・ローカルなUndo/Redoはエディタが処理し、トランスポートやプロジェクト構造編集のショートカットへ漏らさない

**オーディオファイルブラウザ（第2スライス）**

| 項目 | 決定内容 |
|---|---|
| 初期フォルダ | macOS のダウンロードフォルダ（`~/Downloads`） |
| ナビゲーション | 戻る／進む／親フォルダ。現在位置はプロジェクトを開いている間だけ保持 |
| 一覧 | フォルダ＋対応音声ファイルのみ。その他のファイルと隠しファイルは表示しない |
| 選択 | 単一選択 |
| 試聴UI | 選択ファイル名・長さ・再生／停止だけ。波形・シーク・試聴音量スライダーは入れない |
| 試聴挙動 | プロジェクト再生と重ねて再生可能。別ファイルの試聴開始、ブラウザを閉じる、取り込み開始、プロジェクトを閉じると停止 |
| ドラッグ取り込み | ブラウザからタイムラインへドラッグ。既存オーディオトラック上はそのトラック、空白は新規オーディオトラックへ、表示中の最小グリッドにスナップして配置。MIDIトラック上は不受理 |
| ダブルクリック取り込み | 新規オーディオトラックを作り、現在の再生ヘッドを表示中の最小グリッドへスナップした位置に配置 |

### コードベース調査結果

- `MainComponent::resized()` は「上部バー → 下部パネル → 左FX → トラックヘッダー → タイムライン」の順で領域を切っている。右パネルを上部バー直下の全高にするには、上部バーを除いた直後に右領域を先取りし、その残りから下部パネルを取る
- 上部バー右側には `settingsButton` があり、右パネル用アイコンをその左へ追加できる。既存の `IconButton` を拡張すれば描画・ホバー・ツールチップの流儀を揃えられる
- 左FXパネルには開閉状態をコンポーネントが持ち、`MainComponent` がレイアウトを更新する既存パターンがある。右パネルも同じく表示状態はメッセージスレッド側だけで管理できる
- `Project::save()` / `load()` はトップレベルJSONを構築・復元し、`Project::currentVersion` は現在6。メモはトップレベルの文字列として追加でき、旧JSONはキー欠損時に空文字で補完できる
- `UndoStack` は `tracks` と `markers` の構造編集専用。メモ全文をプロジェクト構造Undoへ混ぜると、ノート編集等のUndoでメモまで巻き戻るため、メモは `TextEditor` のローカルUndoを使い、既存 `UndoStack` の対象にはしない
- 外部音声の取り込み実体は実装済み:
  - `AudioImporter`: WAV/AIFF/FLAC/MP3/M4A等をデコード・プロジェクトSRへ変換して `clip-NNN.wav` 化
  - `TimelineView::LaneContent`: Finder D&Dの座標から対象トラック・スナップ済み位置を算出
  - `MainComponent::startImport(source, targetTrack, startSample)`: 既存トラックまたは新規トラックへの配置入口
- 対応拡張子判定は現在 `TimelineView::isImportableAudioFile()` に局所化されている。ブラウザと判定がずれないよう共通ヘルパへ抽出する
- `MainComponent::getNextAudioBlock()` は `PlaybackEngine::process()` へ転送するだけで、`audio/` と `ui/` のスレッド境界が保たれている
- 試聴は新規機能。オーディオコールバックでファイルI/O・デコード・ヒープ確保・ロック・参照カウント破棄を行わない必要がある（`GOTCHAS.md`）。読み込みはワーカー、再生データの差し替えは既存 `SnapshotExchange` 型の所有権交換、コールバックは不変バッファの読み出しと加算だけにする
- `SnapshotExchange` は `PlaybackSnapshot` 専用の非テンプレート実装なので、試聴では既存クラスを直接再利用せず、同じ pending/current/retired 規則の試聴専用exchangeを新設する（汎用化のためだけの既存クラス変更はしない）
- `GOTCHAS.md` の WindowedSinc に関する注意（100入力サンプルのアルゴリズム遅延・終端ゼロパディング・available==0でも起きる先読み）はオフライン変換で実際に踏んだ罠。試聴は音質要求が低く、リアルタイムのストリーミング境界を複雑にする価値がないため、WindowedSincは使わず線形補間で構造的に回避する
- `TimelineView::LaneContent` は現在 `juce::FileDragAndDropTarget`（Finder等からの外部D&D）のみ。右ブラウザからの内部D&Dには別インターフェース `juce::DragAndDropTarget` を追加し、両入口の後段だけを共通化する必要がある
- `MainComponent` の既定サイズは1100×700、左FXは156px、トラックヘッダーは200px。右パネル表示時にも中央領域を確保できるが、極端に狭いウィンドウでも不正な矩形を作らない防御的クランプが必要

### Phase 5: ロックフリーなファイル試聴 [AI🤖]

- [x] `audio/` にファイル試聴専用クラスを追加する
  - 再生ボタンで選択ファイルをワーカースレッドへ渡し、デコードはワーカー側だけで実行
  - 1chはモノ、2ch以上は先頭2ch。破損・非対応・既存上限を超える長時間ファイルは失敗としてUIへ返す
  - ワーカーの結果は「不変AudioBuffer＋元サンプルレート＋総フレーム数」のスナップショットにする
- [x] 試聴スナップショットを既存 `SnapshotExchange` と同じ所有権規則でオーディオスレッドへ渡す
  - 既存 `SnapshotExchange` は `PlaybackSnapshot` 専用なので直接再利用しない。同じパターンの試聴専用exchangeを新設する
  - 既存exchangeのテンプレート化は影響範囲を広げるため行わない
  - pending/current/retired方式で、生存中バッファをオーディオスレッドから解放しない
  - retiredデータの解放とワーカー結果の回収は`MainComponent::timerCallback()`等のメッセージスレッドで行う
  - 再生／停止／世代番号／再生完了はlock-free atomicで通知する
- [x] `PlaybackEngine` の最終出力へ試聴音を加算する
  - プロジェクトの再生状態に関係なく試聴を進める
  - 元SRとデバイスSRが異なる場合は、オーディオスレッド上で**線形補間**する（試聴用途。コールバック内の確保・ロックなし）
  - WindowedSinc/Lagrange等の状態付き補間器は使わない。全入力バッファが不変で手元にある状態から `floor(sourcePos)` と次サンプルを境界チェックして読む方式に固定し、コールバック境界をまたぐ位置は `double sourcePos` だけで保持する
  - 末尾は「次サンプルが無ければ現在サンプルを使う」、`sourcePos >= numFrames` で完了とし、補間器による先読み・終端ゼロパディング・アルゴリズム遅延そのものを発生させない（`GOTCHAS.md` のWindowedSinc罠を構造的に回避）
  - モノはL/Rへ同量、ステレオはL/Rを維持
  - クリップ／バス／Master処理の後へ保守的な固定ゲインで加算し、プロジェクトのMasterや書き出し結果には含めない
  - デバイスブロックが事前確保上限を超えた場合も境界外アクセスせず、試聴だけを安全にスキップ
- [x] 次の操作で確実に試聴を停止する
  - 停止ボタン
  - 別ファイルの試聴開始
  - files modeを閉じる／notesへ切り替える
  - インポート開始
  - プロジェクトを閉じる／アプリ終了
  - オーディオデバイスの再準備・解放
- [x] 読み込み中・再生中・完了・失敗をブラウザUIへ反映し、ボタン連打やファイル削除との競合を世代番号で無効化する
- [x] 試聴の読込開始・停止・失敗を既存ログへ記録する（オーディオスレッドから直接ログ出力しない）
