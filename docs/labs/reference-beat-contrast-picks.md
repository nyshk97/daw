# 近接した否定例（作りたい方向とズレる市販ビート）

YouTubeで「typebeat chill」等を検索して上位に出た曲のうち、**曲として悪くはないが自分が作りたい
方向とは少しズレる**もの。「嫌いな曲」でも「ジャンルが遠い曲」でもない。

`reference-beat-picks.md` の正例23曲と同じパイプラインで分析し、好き／嫌いの分類ではなく
**作りたい境界を連続的な条件として見つける**ための対照群として使う。

全曲がtype beat＝インスト。正例23曲はボーカル入り完成曲なので、ボーカルの有無・マスタリング差・
配信音圧は好みの差ではなく制作条件の差として扱う（planのconfound監査を参照）。
