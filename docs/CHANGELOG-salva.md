## 書き方

このセクションは AI が release-salva.sh の pause 中に `[Unreleased]` を埋めるときの判断基準でもある。

- 1 項目 = 1 行の `- ` bullet。インライン Markdown は `` `code` ``、`**strong**`、`[label](url)` のみサポート（Sparkle description の HTML 変換が対応するのはこれだけ）

## [0.3.0] - 2026-08-15
### ✨ Added

- ヘッダー左端に「‹」ボタンを追加: クリックでファイルを閉じてスタート画面へ戻れる（`⌘W`・ウィンドウの×と同じ動き）

### 📝 Changed

- 録音を保存ダイアログなしの自動保存に変更: 録音ボタンだけで即開始し、`record-日付-時刻.wav` の自動命名で `~/Music/salva` へ保存。停止するとそのままそのWAVが開き、保存先はトーストで表示（保存先フォルダは録音画面にも常時表示）
- 録音画面をボイスメモ型のフルブリード表示にリデザイン: 経過リング付きの円形録音ボタン・録音中に流れる波形ロール・dB目盛りとピークホールド付きメーター・大型タイマー。出口は左上の「← 戻る」に統一し、「録音モード」という呼び名を廃止
- 録音ボタンの表記を「新規録音」に変更（赤ドットは文字でなくアイコン描画に）
- ボタンの見た目を3階層スタイルに統一（オレンジ塗りの主役 / アイコン付き / 枠なしゴースト）。再生ボタンは円形アイコンになり、スタート画面のカードは上のボタンにマウスを乗せてもカード全体が光るように
- ヘッダーの「Salva」表記をやめ、開いているファイル名を太字の主役に（サンプルレート等のフォーマット情報は隣に控えめ表示）

## [0.2.0] - 2026-08-15
### ✨ Added

- スタート画面を刷新: レコード盤のドロップターゲットと「ファイルから」「レコードから」の2カード構成に。最近開いたファイルはホバーで反応する行カードになりクリックで開ける
- 「ファイルを選択…」ボタンと `⌘O` でファイルを開けるように（ドラッグ&ドロップ以外の入口）
- ファイルをドラッグ中はレコード盤が回転して受け付け中であることを表示
- ×ボタン・`⌘W` が「1段戻る」に: ファイルを閉じてスタート画面へ戻る（スタート画面でのみアプリ終了。録音中は誤操作防止のため無効）

### 📝 Changed

- 配色をアプリアイコン基準に刷新（チャコール地＋オレンジのアクセント）。ポップアップメニューとComboBoxも角丸の専用スタイルに
- ステムのM/Sパネルを波形右の固定カラムへ移動。`ORIGINAL / 4 STEMS / 6 STEMS` の切替で波形の高さが動かなくなり、メーターはコンパクトに
- ステム切替タブとステム分離ボタンの表記を `ORIGINAL / 4 STEMS / 6 STEMS`・`STEM分離` に変更
- 録音ボタンの表記を「● 新規録音」に変更（録音モード中は「録音モードを終了」）
- 分離済みファイルではSTEM分離ボタンを「分離済み」表示にして再実行できないように

### 🐛 Fixed

- 再生開始やループ再生のたびに選択範囲の頭 約10ms が欠けて鳴る問題を修正（「読み込み遅延」の誤カウントも解消し、本当に途切れたときだけ表示されるように）

## [0.1.0] - 2026-08-15
### ✨ Added

- 初回リリース。レコード/ローカル音源から欲しい区間を素材化するアプリ
- オーディオファイルの読み込み（D&D・最近開いたファイル。wav/aiff/flac/mp3/m4a）と波形表示・区間ループ再生・横ズーム（`⌘←/→`）
- レコード録音モード（入力デバイス＋ステレオペア選択・24bit WAVストリーミング書き込み・レベルメーター。`r` = 録音）
- ステム分離（demucs 4/6ステム）とステムごとのミュート/ソロ再生・レベルメーター
- 区間の書き出し（聴こえている構成のミックス・24bit・元サンプルレート・ファイル名にBPMを焼き込み）
- 区間からのBPM逆算表示（4/4固定・小節数はクリックで手動修正可）
- Sparkle によるアプリ内アップデート（アプリメニューの Check for Updates…）
