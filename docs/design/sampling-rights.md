# サンプリングの権利まわり — リスクの見立てと帯分け

2026-08-14 の壁打ちで確定。上モノ調達を実曲サンプリングへ転換する検討（labs 2026-08-14:
帯内パックループ5本の耳確認で「2軸選別では足りない」が確定）の一部として、公開・収益化を
前提にどこまで許容するかを決めた。

**確度の注記**: 法制度の部分（保護期間・権利の構造）は確かだが、「実態」の帯分けは
判例や統計ではなく**執行の経済構造から引いた推論**。中間帯で実際に何が起きるかの
公開データは存在しない。線は保守的に読む。

## 前提（本人の活動方針とリスク許容）

- 曲は公開する。Spotify等のサブスク配信＋YouTube。個人活動・事務所に入る予定なし
- **許容する**: YouTubeのContent ID claim（その動画の広告収益が権利者に行く）
- **避ける**: 曲の取り下げ（特にSpotify側）・まとまった額の賠償

## 理論（2階建ての権利）

- **著作権**（曲）: 作者の死後70年。JASRAC等の管理団体があるが、サンプリングは改変を伴い
  同一性保持権（人格権・団体が代行できない）まで絡む
- **原盤権**（録音物）: 発行後70年（2018年に50→70年へ延長。概ね1956年以前の録音のみ切れている）。
  包括管理団体が**存在しない**ため、クリアには元レーベルと個別交渉しかない。創作性の要件が
  ないため理論上は1秒でも侵害になり得る

→ 理論値ではインディー規模の正規クリアは事実上不可能。実態は執行の経済学で決まる。

## 実態のモデル — リスクを決める3変数

「古さ」は代理変数。実際に効くのは:

1. **検出**: 原盤がContent IDに登録されているか（メジャーのカタログはほぼ全登録・
   廃盤マイナーは未登録が多い）
2. **特定**: 日本のリスナーが元ネタに気づくか（同じ市場の有名曲は即バレ→SNS経由で権利者に届く）
3. **執行**: 権利者に動く体制と動機があるか（国内メジャー＋JASRACは両方ある・
   消滅した海外レーベルは両方ない）

賠償はほぼ心配無用（実損ベースの日本の賠償額では、個人相手の国際訴訟は権利者の費用倒れ)。
権利者の現実的な手段は**無料でできる2つ**＝Content ID claimと削除申請だけで、リスクの
実体は後者。YouTubeは収益化（claim）を選べるが、**Spotifyには収益を取る選択肢がなく
検出＝削除**。配信代行（DistroKid等）は削除通知が重なるとアカウントごと停止があり、
全カタログが巻き添えになる。

## 帯分け（本人の許容ラインで確定）

| 帯 | 例 | 扱い |
|---|---|---|
| 全面回避 | 国内曲全般（近年ヒットはもちろん、**有名シティポップ含む**。海外リバイバル以降、権利者が資産価値に気づき執行が活発） | 使わない |
| YouTube限定 | 海外メジャーの有名曲 | claimは確実・Spotify取り下げの可能性が残るため、Spotifyには出さない |
| 本命レーン | **海外×30年以上前×マイナー/廃盤レーベル×深めのチョップ** | 3変数すべて緑。許容リスク内 |
| 白 | 1956年以前の録音（原盤権切れ・曲側は別途確認）／Tracklib等のクリア済み実曲サービス | 合法 |

リスクを下げる操作側の変数: フック・サビ・**ボーカル**の丸抜きは特定が桁違いに速い
（伴奏・テクスチャは遅い）。チョップ・ピッチ変更・重ねは検出と特定の両方を下げる。

## 供給源のイメージ

レコード発掘（クレートディギング）を主経路のイメージにしている。中古盤のエサ箱
（110円〜・廉価コーナー300〜800円）は「古い×海外×廃盤×Content ID未登録」＝本命レーンの
物件が物理的に集まる場所で、掘る行為自体が安全側に偏る。**掘るのは洋モノの棚**
（和モノは古くても権利・価格とも高くつく側）。ヴィニールの質感は、パックループに
欠けていた「2軸の外の何か」の候補でもある。取り込み後は既存パイプライン
（Demucs・BPM/キー検出・2軸測定・ライブラリindex）がそのまま使える。

具体設計（機材・取り込みワークフロー・上モノ調達のサンプリング転換の設計本体）は
着手時に /dig で詰める。[reference-beat.md](reference-beat.md) の「音色の調達」の
書き換えもその時に行う。
