# グリッド解像度の上限

2026-07-20 決定（タイムラインのズーム・グリッド細分化の実装時）。

## タイムライン（アレンジビュー）

- グリッドは **1/16音符が上限**。MIDI編集が将来入ってもこの上限は変えない
  - リージョン配置という用途には十分で、Logic のアレンジウィンドウも同じ構造
- **セクションマーカーの配置粒度は拍（1/4小節）が上限**（2026-07-22 追記）
  - 表示グリッドに準拠してスナップするが、グリッドが1/8以下でも拍までしか細かくしない
  - 目的は「2/4小節が挟まる曲」での半小節ずれへの追従。曲構造のラベルにそれ以上の細かさは誤操作リスクしか生まない

## ピアノロール（MIDI編集を実装するとき）

タイムラインとは**別コンポーネント**として作り、そちらに専用グリッドを持たせる。要件:

- **1/32 は必須**
- 1/64 は任意
- **3連符グリッド（1/12・1/24）を忘れずに入れる** — 細かさよりも3連の方が重要

## 後戻り可能性

位置はサンプル単位で保持しているので、内部解像度について後戻り不能な決定は存在しない。表示グリッドの拡張は `TimelineView::gridDivisionsPerBar()` の候補リストと `maxPxPerBar` の定数変更だけで済む。
