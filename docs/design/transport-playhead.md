# 再生ヘッドと再生開始位置

2026-07 に確定。トランスポートまわりを触るとき・「止めた場所」に関わる機能を足すときに読む。

## 2つの印を分ける

1本の線に2つの役割を兼ねさせない。

- **再生ヘッド**（全高の白線＋ルーラー上端の塗り三角）＝ **今どこにいるか**。⌘T の分割・⌘V の貼り付け・ファイル取り込みの基準
- **再生開始位置**（ルーラー上端の**中抜き**三角）＝ **次にどこから鳴るか**。再生・録音の開始点

**分けた理由**: 兼用だと停止した瞬間に食い違う。以前は停止でヘッドを開始位置へ巻き戻していたため、「聴いていて、ここだと思った場所で止めて ⌘T で切る」ができなかった（切りたい位置が消える）。かといって停止位置をそのまま次の再生位置にすると、今度は**同じ場所へのテイク録り直し**が壊れる（歌い終わった位置から録音が始まる）。両方を満たすには印を分けるしかない。

Pro Tools が Play Start Marker を独立して持つのも同じ理由。Logic は停止でヘッドが戻る方式で、これは「開始位置とヘッドが常に一致する」と言い換えられる（＝分割位置を保持できない側に倒した設計）。

## 操作の規則

| 操作 | ヘッド | 開始位置 |
|---|---|---|
| Space で停止 | 止めた位置に残る | 動かない |
| Space で再生 | 開始位置へ飛んで走る | 動かない |
| ルーラー/タイムラインのクリック | 移動 | 一緒に移動 |
| `,` `.` / セクション移動（`;` `'`） | 移動 | 一緒に移動 |
| 録音開始（`r`） | カウントイン開始位置（punchIn の1小節前）へ飛んで走る | punchIn（開始位置を小節頭へ丸めた所）に揃う |
| 録音停止（`r` / Space） | 録り終わった位置に残る | 録音開始小節の頭のまま |
| 書き出し前の停止（⌘B / ⌘E） | 止めた位置に残る | 動かない |

クリックで両方動かすのは、クリック＝「ここから聴きたい」という意思表示だから。分割は ⌘T がヘッド基準で動くのでクリックを必要とせず、**頭出し位置が勝手に失われることはない**。

## ボタンとキーの対応（2026-08-20）

ボタンは ■ ▶ ● の3つで役割固定、状態は点灯で示す（他DAW共通の読み方）。▶/■ を1ボタンで入れ替える方式は「緑の停止ボタン」に見えて読めなかったので廃止。

- **■ 停止**: 再生・シーク再開待ち・録音のどれでも止める（`stopTransport()`）。録音中は録音終了
- **▶ 再生**: 停止中だけ効く。再生中（録音中も）は緑点灯、押しても何も起きない
- **● 録音**: 録音中は赤点灯＋明滅。押すと録音終了（R と同じ）。**再生中に押すと開始位置マーカーへ戻ってカウントインから録る**（その場パンチインではない。「同じ場所へテイクを重ねる」の前提。Logic の R も再生中に押せるが Logic はその場から録る点が違う）
- **Space** だけがトグル（止まっていれば再生・動いていれば停止）。キーボードの作法なのでボタンとは分ける

## 実装の要点

- 位置操作は `MainComponent::locate()`（両方動かす）と `setPlayStart()`（開始位置だけ）の2つ。`playStartSample` へ直接代入しない。「片方だけ動かす漏れ」を型ではなく関数の分け方で防いでいる
- **録音時にヘッドを動かすのは `PlaybackEngine::startRecording()` の仕事**。UI から punchIn へシークを重ねると、エンジンが積んだカウントイン分（`punchIn - countInSamples`）が上書きされて1小節のカウントインが消える
- 編集位置・白線の描画・再描画のキャッシュ判定は `TransportState::uiPositionSample()` に寄せる。`seekRequest` はオーディオコールバックで初めて `playheadSamplePos` に反映されるため、生の再生位置を読むとクリック直後の1バッファ分だけ旧位置で切れる
- `uiPositionSample()` は**0クランプしない**。カウントイン中のヘッドは負が正しい値で、クランプすると白線が小節1に張り付いて開始位置マーカーと重なる。0以上が要る編集側で `jmax` する

## 意匠と、意図的に見送ったもの

マーカーは**ヘッドと同じ形・同じ大きさの三角を、塗らずに輪郭だけ**で描く（`Theme::playStartMarker`）。「塗り＝今いる場所／中抜き＝次に鳴る場所」の対比にすると2つの関係が読み取れて、重なっているとき（＝ほとんどの時間）はヘッドの塗りに隠れて1本に見える。色を薄めるだけの案は「ヘッドが薄くなっただけ」に見えて役割の違いが伝わらず、右向き三角（Pro Tools 式）は小節番号と窮屈になるため見送った。

- **タイムライン本体に開始位置の縦線を引かない** — 再生中に画面を縦断する線が2本あると「どっちがヘッドか」が一瞬迷う。開始位置は「どこから鳴るか」が分かれば十分で、波形との精密な対比は要らない
- **「開始位置へ戻す」専用キーを作らない** — Space で再生すればヘッドが開始位置へ飛んで分離は自然に解消する。繰り返し聴きはサイクル（`C`）が担う
- **開始位置マーカーのドラッグ移動を作らない** — クリックで両方動くので、頭出しの変更はクリック1回で足りる
