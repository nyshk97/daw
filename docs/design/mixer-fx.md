# ミキサー・FX の確定設計（Tier 2）

2026-07-22 の `/dig` で確定。実装スライスごとに `/plot` で plan 化する。

## 画面構成

### ミキサー = オーバーレイ（`X` でトグル）

- ヘッダー＋タイムライン領域だけを覆い、**FXパネル・下部は隠さない**（send を調整しながらバスFXを見る作業が成立する）
- 表示中も Space 再生・シーク等の再生系ショートカットは有効
- パネルは MIXER タイトルバーのドラッグで移動可

### FX = 「左 = 概要 ＋ 下部 = 詳細」の2段構成

スライス2の実機確認を経て確定（当初検討していた Ableton 式の下部一体エディタは不採用）。

- **左の概要パネル**（`FxEditorView`・幅232px・基本常設・`I` トグル。Logic のインスペクタ準拠）
  - チェーンのスロット一覧 `[EQ][Comp][Ext]`（各行 ON/OFF）＋ Sends ノブ
  - ピアノロールとは独立して共存する
- **下部の詳細エディタ**（`FxDetailView`・高さ260px）
  - スロットのクリックで開き、そのFXの操作UIを**横幅フル**で表示する（Logic のフローティングウィンドウの代替。EQカーブの横幅を確保するのが目的）
  - ピアノロールと下部スロットは排他（後勝ち）
  - 同じスロットの再クリック / ✕ / 概要パネルを閉じる、で閉じる

### 表示対象の追従

- パネルは通常トラック選択に追従する。ただし**ユーザーによるトラック選択のみ**（undo等の内部同期では表示対象を維持する = `selectTrackFromUser` / `selectTrack` の分離）
- バス / Master のチェーンは**ミキサーのストリップクリックで切替**（ミキサーを閉じると通常の追従に戻る）
- 詳細エディタは、トラック→トラックなら同じスロットのまま追従。チェーン構成が変わる切替では閉じる

## チャンネル構成

- **全トラック固定ストリップ**: EQ → Comp → 外部AU 1枠（各 ON/OFF のみ。順序入替・複数挿しなし）＋ send ノブ3個
- **send用の固定バス3本**: Reverb A（短い Room 系想定）・Reverb B（長い Hall/Plate 系想定）・Delay
  - 各バスに該当FXが1個固定（リバーブは種類セレクタを持つ）
  - バスの作成・削除・命名UIは作らない
- **Master 1本**（Logic の Stereo Out 相当）。固定チェーンは **Limiter のみ**
  - グループバスは作らない（欲しくなったら「Vocalバス固定1本＋出力先トグル」で足す）
- **Pan はミキサーのみ**（トラックヘッダーには置かない。[ui-principles.md](ui-principles.md) の「ヘッダーへの情報追加はしない」と整合）
  - ミキサーストリップ = フェーダー・メーター・Pan・M/S・send3・名前。FXチェーン一覧は載せない（下部エディタと重複するため）

## 実装方針

- UIファーストだが、**ゲイン系（Pan・send・Master音量）は最初からエンジンに結線して鳴らす**（ただの掛け算でDSPが要らないため）。EQ/Comp/Reverb/Delay/Limiter のDSPだけプレースホルダで後追いにする
- DSPは **juce::dsp を土台**にする（不満が出た箇所だけ自作に差し替える）
- 6スライスで実装する（1スライス = 1 plan。FXの個別仕様は各スライス着手時に短く dig する）
  1. エンジン土台＋ミキサーオーバーレイ（ステレオ化・Pan・バスsend・Master・保存形式v4）
  2. 下部エディタの器
  3. EQ
  4. Comp
  5. Reverb + Delay + Limiter
  6. 外部AUスロット（RX。レイテンシ補償の要否をここで検討する）

## なぜこの構成か

Logic 踏襲かを迷っていたが、Ableton Session View の「ミキサー帯＋デバイスビュー縦積み」を参考に、**下部の一等地をエディタに渡し、ミキサーをオーバーレイへ逃がす**構成に落ち着いた（ユーザー発案）。窓管理が不要・常設面が最小・自作FXのUIを横長で自由に設計できる、の3点が理由。
